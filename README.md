# 📊 SunCoast Retail Visual Analysis

## 📌 Overview

This project is part of **Module 11: Data Visualization with Matplotlib**. It simulates retail data for a company called **SunCoast Retail** and uses data visualization techniques to uncover trends, relationships, and business insights.

The focus of this project is to apply **Matplotlib** to create meaningful visualizations that support data-driven decision-making.

---

## 🗂️ Project Features

### 🔹 Data Generation

The script generates realistic synthetic datasets including:

* **Quarterly Sales Data** (2022–2023)
* **Store Locations**: Tampa, Miami, Orlando, Jacksonville
* **Product Categories**: Electronics, Clothing, Home Goods, Sporting Goods, Beauty
* **Customer Data**:

  * Age
  * Purchase Amount
  * Price Tier

---

## 📈 Visualizations Included

### 1. Time Series Analysis

* Quarterly sales trends
* Sales comparison across locations

### 2. Categorical Comparisons

* Category performance by location (bar chart)
* Sales composition by location (stacked bar chart)

### 3. Relationship Analysis

* Advertising spend vs. sales (scatter plot + trend line)
* Advertising efficiency over time

### 4. Distribution Analysis

* Customer age distribution (histograms)
* Purchase behavior by age group (box plots)

### 5. Sales Distribution

* Purchase amount distribution (histogram)
* Sales breakdown by price tier (pie chart)

### 6. Market Share Analysis

* Category market share (pie chart)
* Sales distribution by location (pie chart)

### 7. Business Dashboard

* Combined visualization with multiple subplots showing:

  * Sales trends
  * Location performance
  * Ad spend vs sales
  * Category market share
